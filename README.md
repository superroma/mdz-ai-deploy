# mdz-ai-deploy

Skill-driven toolkit to spawn collaborative [MDZ](https://github.com/superroma/mdz) sites
bound to GitHub content repos — with two-way git sync, magic-link invites, and nanoclaw
agents. Generalizes the hand-built `zb-mdz` deployment.

**Principle:** skills for the control plane, code for the data plane.
